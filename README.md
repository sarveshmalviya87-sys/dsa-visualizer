🚀 DSA Visualizer

Interactive Data Structures and Algorithms Visualizer

DSA Visualizer is an interactive web-based platform designed to help students and developers understand Data Structures and Algorithms through visual representations and step-by-step execution.

The project aims to make complex programming concepts easier to understand through an intuitive and user-friendly interface.

---

📌 Project Overview

This project provides an interactive environment for learning and exploring fundamental Data Structures and Algorithms. It helps users understand how different operations and algorithms work through visual demonstrations.

✨ Key Features

- Interactive Data Structure Visualization
- Step-by-Step Algorithm Execution
- User-Friendly Interface
- Responsive Web Design
- User Authentication
- Login and Signup Functionality
- Password Recovery System
- Organized Dashboard

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Functionality and interactions
- Supabase – Authentication and backend services
- Git & GitHub – Version control and project hosting
